# CRUD Fly

A small browser game and shareable animation in which a digital fruit fly plays Crud, the cue-less pool game.

The project is currently in the planning stage. The intended first release combines real game physics, an embodied fly whose throw is driven by a 1,072-neuron subset of the MaleCNS fruit-fly connectome (real recorded wiring, artificial game sensors, simplified dynamics, hand-designed action decoder), a stylized 3D presentation, and deterministic replay. It follows the same pattern and the same disclosure as the recent fly-connectome game demos. It is not a complete brain, not live neural recording, and not evidence of learning.
